# NurlyKoz

Демонстрационный сайт глазной сети. Собран как более ясная альтернатива типичной клинике, где запись живёт только в WhatsApp, а цена появляется после переписки.

Это не [AsiaKoz](https://asiakoz.com/) и не действующая медицинская организация. Тексты, врачи, адреса и телефоны вымышлены. Оригинал изучен по открытым страницам: структура услуг, города, карточки врачей и путь «написать в мессенджер».

## Что здесь удобнее

- Заявка на сайте: город → услуга → врач → окно → контакты.
- Вилка цен до визита, точная сумма только после диагностики.
- Фильтр врачей. Если связки нет, это сказано прямо.
- Отдельный острый маршрут (вспышки, занавеска, травма).
- Страницы услуг с подготовкой, ограничениями и вопросами.
- Филиалы с разными часами.

## Запуск

```bash
npm install
npm run dev
```

Сайт открывается на [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Стек

Next.js, TypeScript, Tailwind, shadcn/ui. Данные клиники лежат в `src/lib/clinic.ts`, без базы и без чужих фото.
